End-to-End Orchestration Workflow

Dual-path classification with grounded retrieval

STAGE 01

Dual-Path Classifier

Evaluates deterministic keyword signatures in <1ms. If confidence is below threshold, seamlessly offloads to Groq LLM inference.

STAGE 02

Vector RAG Search

Transforms input via sentence-transformers into 384-dimensional dense vectors and performs cosine distance queries across Qdrant Cloud.

STAGE 03

Grounded Drafter

Feeds retrieved historical support pairs into Groq with strict constraint prompting to enforce 280-character Twitter brand guidelines.

STAGE 04

Escalation Engine

Enforces organizational guardrails, financial safety protocols, and legal keyword traps to safely route between auto-reply and human desk.
